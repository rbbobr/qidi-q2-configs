# QIDI Q2: пользовательский профиль 01.01.03.02

`default/` — неизменённый заводской снимок из `eb638f1`.
`custom/` — пользовательские настройки на базе ветки `qidi-studio`,
обновлённые для прошивки **01.01.03.02** и двух режимов подачи: Box и внешняя катушка.

Описание изменений, ограничения, установка, откат и аппаратные проверки:
[UPGRADE-01.01.03.02.md](UPGRADE-01.01.03.02.md).

Проверки шаблонов и последовательностей команд:

```sh
python -m pip install -r tests/requirements.txt
python -m unittest discover -s tests -v
```

Тесты не заменяют загрузку конфигурации в QIDI Klipper и проверку на принтере.
В репозитории отсутствуют штатные `MCU_ID.cfg`, `box.cfg`, `timelapse.cfg`
и реализация модулей Box.
